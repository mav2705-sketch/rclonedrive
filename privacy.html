Privacy Policy

RcloneDrive is a personal application used by its owner to access Google Drive through rclone.

Data Access

The application requests Google Drive access to read, create, update and manage files as authorized by the account owner.

Data Storage

OAuth credentials are stored locally in the owner's rclone configuration. File content may be temporarily cached on the owner's device.

Data Sharing

The application does not operate an independent server for collecting user data. Data is not sold to advertisers.

Access Revocation

The owner can revoke access through Google Account security settings.
